# Felix Plaza 3D

Interactive 3D model of Felix Plaza's five levels (Concourse to Third Floor), built from the brand zoning plan dated 10 Oct 2026.

- **3D**: all floors stacked, or one floor at a time
- **Plan**: top-down view matching the printed drawing
- **Walk**: first-person walkthrough with a floor map
- Directions between entrances, lifts and shops; measuring; placing standees, kiosks and decor; saved views for presenting

Open `index.html` through any static web server (it loads `data.json` and `tex/`).

On GitHub Pages, placed items and edits are saved in the viewer's browser only. Use **File** to export or import a layout.
